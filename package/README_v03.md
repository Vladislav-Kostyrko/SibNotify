# SibNotify 0.3 — конструктор панели

Панель больше не фиксированная: собираешь её сам из блоков.

## Можно добавить

Система · Задачи Б24 · Комментарии · Чаты Б24 · Mattermost · Telegram · Календарь · Почта · Погода · Часы

Кнопка **«+ Добавить блок»** внизу панели → плитки типов → окно подключения (вебхук Б24 / токен ММ / iCal / токен бота) с кнопкой «Проверить подключение» → «Добавить».

## Управление блоками

- **Высота** — тянуть за полоску над блоком или задать в настройках блока (⚙ на заголовке).
- **Порядок** — ▲ ▼ на заголовке.
- **Удалить/изменить** — ⚙ → «Удалить блок» / правки.
- **Ширина панели** — ⚙ в шапке → «Ширина окна, px».
- **Сторона экрана** — кнопка ⇄ в шапке или «Сторона: слева/справа» в настройках. Полоска и панель переезжают к другому краю.
- Полоска перетаскивается мышью между мониторами, положение запоминается.
- В фуллскрине (игры, кино, презентации) панель не выезжает.

## Установка

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

Дальше всё настраивается прямо в панели: добавь блок → впиши вебхук/токен → «Проверить подключение».

## Данные

- **Б24**: `https://b24.sibtrans.ru/rest/<ID>/<TOKEN>/`, права `tasks`, `im`, `user`, `calendar`.
- **Mattermost**: личный access token (Профиль → Безопасность → Персональные токены).
- **Календарь**: ссылки `.ics` (Яндекс: Настройки → Экспорт); события Б24 идут автоматически.
- **Telegram**: токен бота от @BotFather (пока сообщения боту; личные чаты — следующий этап).
- **Почта**: блок-заглушка, подключение IMAP/Exchange — следующим шагом.

Конфиг: `%APPDATA%\ru.sibtrans.notify\config.json`.
Удаление: `.\install.ps1 -Uninstall`.
